# Credit-Card-Fraud-Detection
Machine learning model using Random Forest and CART algorithms.

## Dataset Info
The dataset used for this model is quite large, so it cannot be uploaded directly to GitHub due to size limitations. 

You can download the original dataset used for training this model directly from Kaggle using the link below:
[Credit Card Fraud Detection Dataset on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
